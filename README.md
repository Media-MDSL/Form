# Smarter Navigation, Safer Seas: Insights from Anschütz & Jotron
Registration form for the Multidigital Virtual Webinar Series, 2nd edition (11 November 2026, 10:00 AM WAT).

## Go-live checklist
1. Create a new Google Sheet, copy its ID into `SHEET_ID` in `code.gs`.
2. Paste `code.gs` into Extensions > Apps Script, then Deploy > New deployment > Web app (Execute as: Me, Access: Anyone).
3. Paste the Web App URL into `SCRIPT_URL` at the top of `index.js`.
4. Push all files to the GitHub repo (https://media-mdsl.github.io/Form/).
5. Submit a test registration and confirm the row appears in the sheet.
